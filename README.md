# AcordeEDU

Portal de cifras e acordes musicais com interface responsiva em HTML, CSS e JavaScript.

## Acessar o site

https://pacheco-3d.github.io/acordedu/

## Recursos

- Catálogo pesquisável de músicas e artistas
- Navegação entre músicas, artistas e estilos
- Carrossel de artistas
- Transposição de acordes e rolagem automática nas cifras disponíveis
- Favoritos pessoais salvos no navegador
- Metrônomo, notas de referência para afinação e dicionário básico de acordes
- Layout responsivo para computador e celular

## Organização

- `index.html`: página inicial
- `assets/site.css`: estilos
- `assets/site.js`: navegação e ferramentas
- `assets/catalogo.js`: catálogo de músicas e artistas
- `assets/logo.svg`: marca do AcordeEDU

## Desenvolvimento e conteúdo

O AcordeEDU possui identidade visual própria e catálogo em expansão. As fichas do catálogo podem conter apenas metadados quando a cifra ainda não tiver sido cadastrada. As imagens decorativas não devem ser confundidas com fotos oficiais dos artistas ou capas oficiais de álbuns.

Antes de publicar letras, cifras integrais ou imagens de terceiros, confirme as permissões e licenças correspondentes. Esta versão estática salva favoritos no próprio navegador; login e sincronização de repertórios exigem integração com serviço de autenticação e banco de dados.

## Publicação

O site é hospedado no GitHub Pages, com implantação automática a partir da branch `main`.
